# EJ Huang Resume — GitHub Pages

此版本已加入 Primax Electronics Ltd.，2025.03 - Present 的經歷。保留原履歷內容，僅修正少數拼字、大小寫及排版。

## 本機查看

將整個資料夾解壓縮後，用瀏覽器開啟 `index.html`。不需要 Node.js、npm 或 build 步驟。

## 放到 GitHub Pages

1. 建立或選擇 GitHub repository。
2. 將本資料夾中的檔案上傳到 repository 根目錄；`index.html` 必須位於根目錄，不要多包一層資料夾。
3. 開啟 repository 的 **Settings → Pages**。
4. 在 **Build and deployment → Source** 選擇 **Deploy from a branch**。
5. Branch 選 **main**，資料夾選 **/(root)**，按 **Save**。
6. 部署完成後，使用 Pages 設定頁顯示的網址。一般 project repository 會是 `https://USERNAME.github.io/REPOSITORY/`。

官方說明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 檔案

- `index.html`：完整英文履歷；可直接修改文字。
- `styles.css`：桌面、手機與列印樣式。
- `EJ_Huang_Resume.pdf`：下載按鈕使用的履歷 PDF。
- `.nojekyll`：停用 Jekyll 處理。
- `resume.json`：本次內容的結構化副本，供未來編輯參考；修改它不會自動更新 HTML 或 PDF。

這是可部署的網站檔案包，尚未發佈到 GitHub Pages。聯絡資訊與原履歷一致。若不希望公開手機號碼，請先同步調整 HTML 和 PDF。
